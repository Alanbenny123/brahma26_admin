Brahma26 Admin Dashboard
A modern admin dashboard for managing the Brahma Ashwamedha event system.

🚀 Quick Start
Install dependencies

Set up environment variables

Create .env.local:

Run the app

Open http://localhost:3000

✨ Features
User Management - Create, edit, and delete users
Event Management - Manage events and registrations
Ticket System - Issue and track tickets with QR codes
Attendance Tracking - Monitor event attendance
Transaction History - View payment records
Admin Logging - Track all admin activities
🛠️ Tech Stack
Next.js 14
Appwrite (Backend)
Firebase (Storage & Sync)
Tailwind CSS
TypeScript
📝 Default Login
Use the Appwrite console to create your first admin account.
